機能 概要 SharePointでの使い方
① Microsoft Search
People 検索
今日から使える・設定不要		 SharePoint・Outlook・Teams共通の人物検索。名前・部署名を入力するだけ。メールアドレス・部署・役職・電話番号（登録済みの場合）を表示。 各ページの検索バーから利用可能。「田中」と入力すれば田中さん全員のカードが出る。

設定工数：小〜中		 SharePointの Modern ページに「Microsoft Search Web パーツ」を配置し、スコープを「People（ユーザー）」に設定。独立した電話帳ページとして機能する。 サイトナビゲーションに「👥 社員電話帳」としてリンク。部署フィルタなどの絞り込みも設定可能。
③ Entra ID プロファイルカード
今日から使える・設定不要		 Teams・SharePoint・Outlook上でメンバーの名前にマウスオーバー（またはタップ）するとプロファイルカードが表示される。チャット開始・メール送信も可能。 SharePointのニュース記事や文書ライブラリの「作成者」欄から自然に活用できる。

今日から使える・設定不要		 Exchange Online の標準機能。全職員が自動登録される。Outlookのアドレス帳ボタンから部署別・五十音順で一覧閲覧。 SharePoint上ではなくOutlook側の機能。メール送信時の宛先検索として日常的に使える。

Garoonのアドレス帳は「氏名・部署・役職・内線番号の一覧を部署フィルタや名前検索で絞り込む」という使い方です。この使い方に最も近い順で整理します。

今日から使える

前提：Entra ID プロファイルの整備（最重要）

⚠️ 2026/8/6定例で判明：現在のEntra IDは部署・役職・内線番号がほぼ未入力です。
プロファイルが未入力だとアドレス帳機能は何も表示されません。 どの方法を採用しても、Entra IDに以下の情報が登録されていることが前提です。
→ GaroonからのID移行時にプロパティも移行する必要があります。担当ベンダーに移行可能な範囲・方法を確認中。
項目 Entra IDの属性名 優先度 登録方法
氏名（表示名）displayName必須アカウント作成時に設定済みのはず
メールアドレスmail / userPrincipalName必須Exchange Online移行で整備済み
部署department高管理者がEntra ID管理センターで入力 または CSVインポート
役職jobTitle高同上
電話番号（内線）businessPhones中同上（内線番号を整理してから入力）
オフィスの場所officeLocation低鷹の台・市ヶ谷など

※ プロファイル情報はEntra ID管理センターでCSV一括インポートが可能。約800名分の職員データがあれば効率的に整備できます。
