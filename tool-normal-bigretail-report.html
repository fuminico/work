調査方法と限界

・673名称の大半はクラウドSaaS・RPA・AI-OCR・生成AIなどで、量販店では通常扱われません。ブランド名から「量販店で売られていそうなもの」を選び、ヨドバシ.com・ビックカメラ.comの商品ページを検索して確認しました。

・確認できなかったもの：Visio Standard 2024（ヨドバシ.comでは商品ページを確認できず）、Zoom / Canva / Notion / ChatGPT / Claude / Google Workspace 等のSaaS（量販店の商品ページを確認できず）。

・除外したもの：Adobe製品の「グループ版」「MP- C Level（VIP契約）」、Microsoft 365のTeamsなし版・Copilot併用版・OLV版、事業者独自名の「オフィスあんしん365」等。量販店で売られているのは個人・小規模向けの通常版であり、これらの法人契約版は同一商品と見なせないためです。

・ヤマダデンキ等は個別に照合していません。判定は主にヨドバシ.comの商品ページ（ビックカメラは一部）に基づきます。量販店の取扱は随時変わるため、申込前に最新の在庫をご確認ください。
